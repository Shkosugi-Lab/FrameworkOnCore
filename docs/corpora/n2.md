# n2(N2 CMS)

CMS です(Web Forms、C#)。データは SQLite(`App_Data`)に置きます。[共通の準備](setup.md) が終わっている前提で、コマンドは `C:\foc` で実行します。

| | |
|---|---|
| 取得元 | [n2cms/n2cms](https://github.com/n2cms/n2cms) コミット `db0ec9d1` |
| ライセンス | LGPL 2.1 |
| 追加で要るもの | Build Tools。ディスク約 6 GB |

## 1. GitHub から取得する

```powershell
curl.exe -L -o n2.zip https://github.com/n2cms/n2cms/archive/db0ec9d193040e64ccbec65604c4599da67a4271.zip
tar -xf n2.zip
Rename-Item n2cms-db0ec9d193040e64ccbec65604c4599da67a4271 n2cms
```

## 2. 変換する

元のアプリをソリューションでビルドし、リポジトリの準備の手順を 1 つ実行してから変換します。`--original-step` がその手順です。

```powershell
C:\src\FrameworkOnCore\converter.ps1 C:\foc\n2cms\src\WebForms\WebFormsTemplates\N2.Templates.csproj --out C:\foc\out\n2 --root C:\foc\n2cms --build-original auto --original-step "build\n2.proj;Templates-PrepareDependencies"
```

## 3. Linux で動かす

```powershell
cd C:\foc\out\n2
docker build -t n2 .
docker run -d -p 8080:8080 --name n2 -v n2-data:/app/App_Data n2
```

http://localhost:8080/N2/Installation/Begin/Default.aspx?action=install を開き、N2 のインストーラーを次の順に進めます。

1. 管理者のパスワードを決めます。
2. `admin` とそのパスワードでログインします。
3. テーブルを作ります。
4. サンプルのコンテンツを入れます。

終わると、トップ(`/`)にサンプルのコンテンツが出ます。管理画面は `/N2/` です。

記録では、Linux でインストーラーが終わり、トップにコンテンツが出ました(2026-10-11)。ただし、この Dockerfile での手順そのものは試していません。

## 4. 片付け

```powershell
docker rm -f n2
docker volume rm n2-data
```
