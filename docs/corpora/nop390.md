# nop390(nopCommerce 3.90)

EC サイトです(ASP.NET MVC 5、C#、SQL Server)。[共通の準備](setup.md) が終わっている前提で、コマンドは `C:\foc` で実行します。

| | |
|---|---|
| 取得元 | [nopSolutions/nopCommerce](https://github.com/nopSolutions/nopCommerce) タグ `release-3.90` |
| ライセンス | nopCommerce Public License 3.0 |
| 追加で要るもの | Build Tools。ディスク約 3 GB |

## 1. GitHub から取得する

```powershell
curl.exe -L -o nop390.zip https://github.com/nopSolutions/nopCommerce/archive/refs/tags/release-3.90.zip
tar -xf nop390.zip          # nopCommerce-release-3.90 ができる
```

## 2. 変換する

元のアプリをソリューションでビルドしてから変換します(`--build-original auto` が判断します)。

```powershell
C:\src\FrameworkOnCore\converter.ps1 C:\foc\nopCommerce-release-3.90\src\Presentation\Nop.Web\Nop.Web.csproj --out C:\foc\out\nop390 --root C:\foc\nopCommerce-release-3.90 --build-original auto
```

## 3. Linux で動かす

```powershell
docker network create foc-net
docker run -d --name foc-sql --network foc-net -e ACCEPT_EULA=Y -e "MSSQL_SA_PASSWORD=Foc_local_Passw0rd" mcr.microsoft.com/mssql/server:2022-latest
cd C:\foc\out\nop390
docker build -t nop390 .
docker run -d -p 8080:8080 --name nop390 --network foc-net nop390
```

http://localhost:8080/ を開くと、インストールの画面が出ます。次の値でインストールします。

| 欄 | 値 |
|---|---|
| SQL Server | `foc-sql` |
| 認証 | SQL Server 認証。ユーザー `sa`、パスワード `Foc_local_Passw0rd` |
| サンプルのデータ | 入れる |

インストールが終わると、店頭と管理画面が開けます。管理画面には、インストールの画面で入れたメールとパスワードでログインします。

記録では、店頭 19 画面、カートへの追加、管理画面 7 画面がどれも 200 でした(2026-10-11)。

## 4. 片付け

```powershell
docker rm -f nop390 foc-sql
docker network rm foc-net
```
