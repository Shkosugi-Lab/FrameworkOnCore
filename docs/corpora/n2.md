# n2(N2 CMS)

CMS です(Web Forms、C#)。データは SQLite(`App_Data`)に置きます。[共通の準備](setup.md) が終わっている前提で、コマンドは作業フォルダー(下の 0)で実行します。

| | |
|---|---|
| 取得元 | [n2cms/n2cms](https://github.com/n2cms/n2cms) コミット `db0ec9d1` |
| ライセンス | LGPL 2.1 |
| 追加で要るもの | Visual Studio か Build Tools。ディスク約 6 GB |

## 0. FrameworkOnCore を取る

作業用の空のフォルダー(例: `C:\foc`。パスは短くします)を作って移り、そこに FrameworkOnCore を取ります。以降のコマンドは、すべてこのフォルダーで、ここからの相対パスで実行します。ほかのコーパスで済ませてあれば、この手順は飛ばします。

```powershell
New-Item -ItemType Directory -Force C:\foc | Out-Null
cd C:\foc
git clone https://github.com/Shkosugi-Lab/FrameworkOnCore.git
```

## 1. GitHub から取得する

```powershell
curl.exe -L -o n2.zip https://github.com/n2cms/n2cms/archive/db0ec9d193040e64ccbec65604c4599da67a4271.zip
tar -xf n2.zip
Rename-Item n2cms-db0ec9d193040e64ccbec65604c4599da67a4271 n2cms
```

## 2. 変換する

元のアプリをソリューションでビルドし、リポジトリの準備の手順を 1 つ実行してから変換します。`--original-step` がその手順です。

```powershell
.\FrameworkOnCore\converter.ps1 .\n2cms\src\WebForms\WebFormsTemplates\N2.Templates.csproj --out .\out\n2 --root .\n2cms --build-original auto --original-step "build\n2.proj;Templates-PrepareDependencies"
```

**Studio で入れる値**([使い方](setup.md#42-studio-で))

| 欄 | 値 |
|---|---|
| プロジェクト | `.\n2cms\src\WebForms\WebFormsTemplates\N2.Templates.csproj` |
| リポジトリのフォルダー | `.\n2cms` |
| 構成 | `Release` |
| 追加の手順(ステップ 1 の「元のアプリのビルド」で開いて入れる) | `build\n2.proj;Templates-PrepareDependencies` |

## 3. Windows で動かす

インストールで `App_Data` が書き換わります。Linux でも試すときは、先に 4 の `docker build` を済ませておきます([共通の準備の 7](setup.md#7-linux-で動かす))。

```powershell
Push-Location .\out\n2\site
dotnet bin\N2.Templates.dll --urls http://localhost:5000
Pop-Location                  # Ctrl+C で止めたあと、作業フォルダーに戻る
```

http://localhost:5000/N2/Installation/Begin/Default.aspx?action=install を開き、N2 のインストーラーを次の順に進めます。

1. 管理者のパスワードを決めます。
2. `admin` とそのパスワードでログインします。
3. テーブルを作ります。
4. サンプルのコンテンツを入れます。

終わると、トップ(`/`)にサンプルのコンテンツが出ます。管理画面は `/N2/` です。Studio では「ネイティブ起動(この PC)」の「起動」を押します。

## 4. Linux で動かす

```powershell
docker build -t n2 .\out\n2
docker run -d -p 8080:8080 --name n2 -v n2-data:/app/App_Data n2
```

http://localhost:8080/N2/Installation/Begin/Default.aspx?action=install を開き、同じようにインストールします。Studio では「コンテナ起動(Linux / Docker)」の「起動」を押します。

記録では、Windows・Linux ともインストーラーが終わり、トップにコンテンツが出ました(2026-10-11)。ただし、このページの手順そのものは試していません。

## 5. 片付け

```powershell
docker rm -f n2
docker volume rm n2-data
```
