# n2(N2 CMS)

CMS です(Web Forms、C#)。データは SQLite に置きます。[共通の準備](setup.md) が終わっている前提です。

|---|---|

| フォルダー | `corpora\work\n2cms-master` |
| ライセンス | LGPL 2.1 |
| 追加で要るもの | Build Tools。ディスク約 6 GB |

## 1. 取得して変換する

元のアプリをビルドしてから変換します。

```powershell
.\corpora\fetch.ps1 -Only n2
.\experiments\wf4c\convert-corpora.ps1 -Only n2
```

## 2. Linux で動かす

サイトをコンテナで動かし、N2 のインストーラーを動かします。インストーラーは、管理者のパスワード、テーブル、サンプルのコンテンツの順に進みます。

```powershell
.\experiments\wf4c\run-linux-site.ps1 -Site n2\site -Dll N2.Templates -Keep
.\experiments\wf4c\n2-install.ps1 -Port 5098 -Running
```

- 確認: `n2-install.ps1` の最後に、トップのコンテンツが出ます(記録 2026-10-11)。
- そのまま http://localhost:5098/ を開けます。管理画面は `/N2/`、管理者は `admin` / `N2admin!2026` です。

## 3. 片付け

```powershell
docker rm -f w2l-site-n2 w2l-sql
```
